# TU TIENDA A LA MANO // E-Commerce Colombia 🇨🇴

Plataforma de comercio electrónico de alta costura urbana y streetwear para Colombia. Incluye pasarela Wompi Bancolombia, sincronización con Supabase PostgreSQL, personalizador visual estilo WordPress (Gutenberg Drag & Drop), optimizador de imágenes WebP y panel de administración completo.

---

## 🚀 Características Principales

- 🛍️ **Catálogo Streetwear**: Cuadrículas interactivas, filtros por categorías, selector de variantes, zoom dinámico HD en prendas y checkout optimizado.
- 💳 **Pagos con Wompi Bancolombia**: Integración con Nequi, Tarjetas de Crédito/Débito, PSE, Botón Bancolombia y Corresponsales.
- 🎨 **Personalizador Visual Drag & Drop**: Constructor de bloques modular (Banners, Videos, Cuadrículas, Testimonios) con temas preconfigurados.
- 📦 **Gestión Logística & Despachos**: Generación de guías con Coordinadora, Servientrega, Inter Rapidísimo y Envía con seguimiento en tiempo real.
- 💬 **WhatsApp Commerce**: Notificaciones automatizadas de pedidos y recuperación de carritos abandonados.
- ⚡ **Optimización de Medios**: Compresión automática a WebP ultraligero en el navegador con balance de aspecto y punto focal.

---

## 🛠️ Tecnologías Utilizadas

- **React 19** + **TypeScript** + **Vite**
- **Tailwind CSS v4**
- **Lucide React Icons**
- **Supabase** (PostgreSQL)
- **Wompi API** (Checkout & Webhooks)

## 💻 Instalación y Desarrollo Local

1. Clonar el repositorio:
```bash
git clone <URL_DE_TU_REPOSITORIO_GITHUB>
cd opus-kartel
```

2. Instalar dependencias:
```bash
npm install
```

3. Iniciar el servidor de desarrollo local:
```bash
npm run dev
```

4. Compilar para producción:
```bash
npm run build
```
